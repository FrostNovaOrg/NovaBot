NovaBot 使用协议

进入控制台之前，请先读一遍下面的约定

N

NovaBot 控制台

先证明你是这台机器的主人

用这台电脑的指纹、面容，或手机上确认一下。不用输口令，也不用验证器。

通行密钥认的是当前访问地址，换了地址（如从局域网换成域名）要重新登记。

或

用口令登录

填的是这个控制台的密码，不是机器人程序界面的口令，两者互不相干。

N

忘记口令

口令没有找回，只能重设

  1. 上服务器，把配置项 novabot.core.config-ui.auth.operator-token 改成 true 并重启。这条通道默认关着，就是为了不留后门。
  2. 启动日志里会印一行带令牌的地址，令牌是那一串。
  3. 把它贴到下面，换一次进入，然后先改口令；改完这条通道会自动关掉并写回配置。
