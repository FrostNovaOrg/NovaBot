# 控制台离线演示

导出目录只需静态 HTTP 服务，不需要 Java、NovaBot 或网络连接。在此目录运行：

```sh
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000/config/`。独立登录页位于 `/config/login/`，
机器人控制台入口位于 `/config/napcat-bootstrap/`，后者只提示需要真实服务。
请从服务根目录打开，不能通过 `file://` 或子目录前缀访问。

页面使用仓库中的正式前端文件。想修改样式或布局，请修改仓库里的文件，再运行
`bash tools/demo-assets/export-console-demo.sh <输出目录>`；可以重复导出到同一目录。
导出只依赖 bash 和 Python 3，不会改动源文件。首次输出请选择空目录。

所有接口读取都来自真实后端的录制响应，方法、路径、查询串、状态码、类型及
SHA-256 见 `console-demo/data/index.json`。录制时仅将 `/status` 的 `configPath`
替换为示意路径 `/opt/novabot/application.yml`，资源用量与启动耗时保留录制读数。
发布录制文件前会检查临时目录、家目录及未声明的账号号码，防止带入本机信息。
查询参数顺序不影响匹配，其他未录制的
组合返回 404 JSON 并在浏览器控制台提示，不会请求在线服务。
预览链接直接打开对应录制文件。页面文件和录制文件都由本地静态服务器提供。

演示中登录态固定为已登录，不要求二次验证；当前时间固定在录制时刻，今天按
Asia/Shanghai 显示。POST、PUT、DELETE 只模拟各接口的回包，改动、消息、告警、
登录退出和向导操作不会保存或发送，刷新或重新读取时仍显示录制内容。
版式预览始终展示真实后端录制的默认版式图片，编辑不会重新绘制。
主播在线查询、通行密钥、令牌签发、机器人自动登录和外部链接只提示需要真实设备或服务。
录制的 `/streamer/name` 使用种子主播的昵称。

种子包含四位演示主播：今天播过的小星、常播的常青、久未开播的远山、已停用的休眠。
共 57 场历史直播，含正常下播、中断及采集缺口。每位主播仅最近 3 场保留分钟明细和报告图，
更早的场次显示真实后端的「没有保留明细数据」提示。
日历含有直播、确认没播、说不准三种状态；粉丝、粉丝团和大航海快照覆盖 181 天。
推送页有三个群、一个私聊，各有不同订阅与开关，其中一个群隐藏金额，周报显示上一期已发出。
只读口令和通行密钥各两条，均明确标为演示；密钥公钥为无效占位值，
口令包含已吊销示例，密钥包含未使用示例。
时间线保留最近四天的成功、失败及静音丢弃记录。推送历史通过真实发送服务与
OneBot 传输替身重放四次投递，仅重放同步发送时的时钟；正式后端不把静音丢弃放入该列表，
请在时间线查看。录制命中、未命中与件数打印到标准输出，不写入导出目录。
`DEMO_SEED=1 bash tools/demo-assets/start-demo.sh` 仍可用于截图；它启动后通过正式的
测试消息接口向本地替身重放同样四次投递，截图实例的推送历史时间为本次启动时间。

首页正在直播与主播实时曲线仍为空：没有替换 B 站连接或虚构在播状态。
远山最近 30 天没有场次、休眠处于停用状态，相关空白与状态一致。
B 站匿名页没有登录二维码，动态同步也不会运行；已有动态推送订阅和时间线示例。

维护录制数据需要 Java 17 和 Maven：在仓库根目录运行
`bash tools/demo-assets/record-console.sh`。它使用独立的完整应用上下文与 MockMvc，
不会开启 HTTP 端口，也不在常规测试中执行。B 站保持匿名断网；仅替换监听端口信息
及 OneBot HTTP 传输，控制器与服务均执行真实代码。历史发送另外固定同步调用的时钟。
录制失败时不会发布新数据。
JSON 回包先多行缩进排版，PNG 仅对 IDAT 数据做无损重压缩，保留像素、尺寸和元数据；
录制器逐字节核对解压后的扫描线。随后按 SHA-256 去重，相同字节的响应共用一个文件。
发布前会拒绝任何超过 10,000 字的文本行。不要用这些响应作为测试的断言基准。

录制日期固定为 2026-10-19 12:00（Asia/Shanghai），重新录制不会随当天日期移动历史场次。
截图启动仍按真实启动日期生成种子。常青保留 7／30／90／180／360 天查询，
其余主播保留 7／30／90 天；开播节奏保留 90／180 天。周报只录推送页的通道预览和状态，停用主播仅录状态；
不录主播页未使用的旧周报接口及额外的 JSON 预览。每份相同字节响应只保存一次；数据目录上限 8 MB，图片上限 2 MB，
超限会使录制失败。
