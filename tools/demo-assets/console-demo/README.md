# 控制台离线演示

导出目录只需静态 HTTP 服务，不需要 Java、NovaBot 或网络连接。在此目录运行：

```sh
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000/config/`。独立登录页位于 `/config/login/`，
机器人控制台入口位于 `/config/napcat-bootstrap/`，后者只提示需要真实服务。
请从服务根目录打开，不能通过 `file://` 或子目录前缀访问。

页面使用仓库中的正式前端文件。想修改样式或布局，请修改仓库里的文件，再运行
`bash tools/demo-assets/export-console-demo.sh <输出目录>`；可以重复导出到同一目录。
导出只依赖 bash 和 Python 3，不会改动源文件。首次输出请选择空目录。

所有接口读取都来自真实后端的录制响应，方法、路径、查询串、状态码、类型及
SHA-256 见 `console-demo/data/index.json`。录制时仅将 `/status` 的 `configPath`
替换为示意路径 `/opt/novabot/application.yml`，资源用量与启动耗时保留录制读数。
发布录制文件前会检查临时目录、家目录及未声明的账号号码，防止带入本机信息。
查询参数顺序不影响匹配，其他未录制的
组合返回 404 JSON 并在浏览器控制台提示，不会请求在线服务。
预览链接直接打开对应录制文件。页面文件和录制文件都由本地静态服务器提供。

演示中登录态固定为已登录，不要求二次验证；当前时间固定在录制时刻，今天按
Asia/Shanghai 显示。POST、PUT、DELETE 只模拟各接口的回包，改动、消息、告警、
登录退出和向导操作不会保存或发送，刷新或重新读取时仍显示录制内容。
版式预览始终展示真实后端录制的默认版式图片，编辑不会重新绘制。
主播在线查询、通行密钥、令牌签发、机器人自动登录和外部链接只提示需要真实设备或服务。
录制的 `/streamer/name` 使用种子主播的昵称。

当前种子只有一位主播、一个群和少量观众。首页没有正在直播的场次，推送历史为空，
没有已签发令牌或通行密钥；粉丝变化、实时曲线、旧场次报告图缺少数据。
主播统计仍可查看历史场次、趋势、日历、观众与周报；动态和登录二维码未录制。

维护录制数据需要 Java 17 和 Maven：在仓库根目录运行
`bash tools/demo-assets/record-console.sh`。它使用独立的完整应用上下文与 MockMvc，
不会开启 HTTP 端口，也不在常规测试中执行。B 站保持匿名断网；仅替换监听端口信息
及 OneBot HTTP 传输，控制器与服务均执行真实代码。录制失败时不会发布新数据。
JSON 回包先多行缩进排版，再按 SHA-256 去重；相同字节的响应共用一个文件。
发布前会拒绝任何超过 10,000 字的文本行。不要用这些响应作为测试的断言基准。
