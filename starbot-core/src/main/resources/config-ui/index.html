发送测试消息

群号填错、Token 不对、机器人不在群里，表现都是「什么都不发生」。发一条真消息是最直接的验证方式。

外部面板

外部面板（如 VRDash 桌面面板）要连事件流，得有一把只读口令。 它只能读——看得到开播、弹幕这些事件，改不了任何配置，也进不了这个控制台。
