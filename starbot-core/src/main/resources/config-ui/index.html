机器人（NapCat 等）

机器人指 NapCat、Lagrange 等 OneBot 实现，NovaBot 通过它把消息发到 QQ。 两个 Token 留空表示保持原值，不会被抹掉。

扫码登录 QQ、查看它自己的运行日志，这些事在 NapCat 的界面里做。 你已经登录了这个控制台，不必再登录它一次——点开时会替你办好。
