# 更新日志碎片

有使用者可见的改动时，新增 `changelog.d/<类>/<短名>.md`，无需直接改 `CHANGELOG.md`。
短名用英文小写和连字符描述改动，例如 `fixed/push-page-known-nickname.md`。
正文写一两句给使用者看的人话，不加开头的 `- `，不写作者或内部工作信息。

- `added`（新增）：新功能或新能力。
- `changed`（变更）：已有功能的行为或使用方式变化。
- `fixed`（修复）：错误修正。
- `security`（安全）：安全问题修复或安全防护改进。

发版前在干净工作树运行 `tools/release/set-version.sh 6.0.1`，统一版本号并将碎片合进
`CHANGELOG.md` 的新版本节。日期默认当天，可用 `--date YYYY-MM-DD` 指定。
同类按文件名排序，合并后删除已用碎片，保留本说明；没有碎片时须明确给 `--allow-empty`。
脚本不提交、不打标签、不推送；检查改动后提交，合进主线再运行发布工具。
