# 第 8 章　群里怎么用命令

这一章是写给**群里的人**看的：怎么查数据、拉报告、订阅提醒。控制台的管理员
不用记这些，转发这一章就行。先说怎么发才算命令，再给整张命令表和几句常见问法。

## 怎么发才算命令

- **群里要先 @ 机器人**：`@机器人 命令名 参数`，比如 `@机器人 直播报告 云山`。
  没 @ 的消息一概不理——群里聊天随口说到某个命令名，它不该接话
- **私聊直接发命令名**，不用 @
- 机器人**只在配置过推送的群里应答**；没配过的群里 @ 了它也不说话
- @ 机器人之后可以直接发 `菜单`。只 @ 一下也会回菜单。发了认不出的命令时，
  开了问数就交给智能助手，没开就回菜单
- 同一个群 **3 秒内只回一次**：执行命令、回菜单、回「本群已关闭……命令」
  「……仅群主、群管理员或超级管理员可用」共用这一份冷却，防的是刷屏

## 命令表

| 命令 | 别名 | 做什么 | 谁能用 |
|---|---|---|---|
| `菜单` | `帮助` `命令` | 列出可用命令 | 所有人 |
| `启用命令 <名称>` | | 恢复一条被本群关掉的命令 | 仅管理员 |
| `禁用命令 <名称>` | | 在本群关掉一条命令 | 仅管理员 |
| `开播@我 [主播]` | `取消开播@我`（只取消） | 订阅开播时被 @。正名是开关，再发一次就取消；别名只取消，不会再订上 | 所有人 |
| `动态@我 [主播]` | `取消动态@我`（只取消） | 订阅发动态时被 @。正名是开关；别名只取消 | 所有人 |
| `@名单 [开播｜动态] [主播]` | `开播@名单` `动态@名单` | 看订阅名单；不写「开播 / 动态」就两份都看 | 所有人 |
| `直播报告 [主播]` | | 直播中查看开播到此刻的报告，下播后可补看上一场的整场报告 | 所有人 |
| `问 〈问题〉` | `问数` | 让智能助手查询直播数据并回答 | 已开启问数的群或私聊中的人 |

提醒订阅按这位主播推到本群的 @ 方式判断：若通知只 @全体成员，会说明订了也不会被单独 @，不加入名单；本群推着这位主播、但这类通知一条也没开的，照样订上，但会说清现在收不到、推送开了才会 @ 你；按订阅名单 @ 或 @全体成员失败后改按名单 @ 的，照常订阅。

几点说明：

- **直播报告怎么指定主播**：群里有多位主播可查时，不点名就会列出带序号的清单，回序号选一位。2 分钟内还能接着回别的序号，再看一位。
  只有一位主播可查时直接出图。命令后跟主播昵称或 UID，直接查那一位。
- **管理员是谁**：群主、群管理员自动就是；机器人的主人未必是每个群的管理员，
  可以在设置页「超级管理员」里填一份跨群生效的名单
- **`@名单` 只写群昵称**（取不到时退回 QQ 昵称），不列 QQ 号
- **`取消开播@我`、`取消动态@我` 只取消，不会再订上。** 正名才是开关：没订就订，订了再发一次就取消。旧名再发一次，也不会把刚取消的订回去
- **名单可以分开关。** `禁用命令 @名单` 会把「开播@名单」「动态@名单」一起关掉。只关其中一类，就点名那一类。
- **几位主播的群里，可以只关一位的。** 直播报告和提醒订阅按主播设置开关：
  `禁用命令 直播报告` 关掉本群每一位主播的这一条，回「已禁用本群 N 位主播的「直播报告」」；
  后面带上主播昵称或 uid，比如 `禁用命令 直播报告 云山`，只关这一位。`启用命令` 同理。
  只关了某一位的，点名查那一位时回「本群已关闭「云山」的「直播报告」」，不点名时只在没关的几位里挑
- **`菜单`（`帮助`、`命令`）、`启用命令`、`禁用命令` 关不掉**，几位主播的群里也一样，发了会回「「菜单」不可开关」这样的话。
  别的插件加的命令不分主播，整个群一起开关

## 向智能助手问数

群里发 `@机器人 问 〈问题〉`，比如 `@机器人 问 昨天播了多久？`。私聊直接发 `问 〈问题〉`。把「问」换成「问数」也可以。聊天里有多位主播时，可以在问题里写明主播昵称或 UID。

可以让助手发某场直播的报告图，说日期、「上一场」或「流水最高那场」都行。同一统计日有几场就几张一起发，每问最多 4 张。较早的场次没有留明细，画不出报告图。群里隐藏金额时，仍能要报告图，但不能按流水挑场次。

只发「问」或「问数」会给三条可照抄的问法，不花钱，也不占额度。没说清时间、指标等口径时，智能助手通常会按常见口径先答，第一行写明采用的口径，例如「按：本月、礼物、个数合计」。

在 QQ 和控制台问同一位主播，花费合计计入这位主播的每日、每周额度，也会计入实例的每周总额。任一额度只剩 25% 或更少时，机器人会在回答末尾提示。额度用完时直接回复恢复时间。

回答末尾有编号选项时，发 `问 1` 或 `问 2` 就能接着问。编号限同一人在同一个聊天里问同一位主播、金额可见设置相同且在 10 分钟内；选主播时仍只回数字。直接用「问」追问也可以。

追问时，智能助手会带上 30 分钟内最近 10 次成功问答的文字。要用之前的数据画图时，可以用 30 分钟内最近 10 轮里查到的数据表。

回答后面带「（由人工智能生成）」。这位主播在当前聊天里要打开「问数」才能用。[通道里的问数开关](07-manage-groups.md#问数)

## 常见问法

**@ 了怎么不理我？** 按顺序查：这个群配过推送吗（没配的群一概不应答）；
这条命令被本群关了吗（被关的会回「本群已关闭……」，点名是哪一条、哪位主播的，不是沉默）；三秒内是不是
已经让它回过一次；最后才是——你发的是命令吗，聊天里提到命令名不算。

**想让开播消息 @ 我？** 自己发 `@机器人 开播@我` 就行，不用找管理员；
不想被 @ 了再发一次同一句。

在 QQ 官方机器人群里，`@机器人 动态@我` 可以订阅动态提醒。机器人用 Markdown 消息 @ 订阅成员，有图时会接着发图。TIM 可能显示「暂不支持该消息类型」，可以用手机 QQ 查看。平台未开放 Markdown 权限时，机器人会改发普通文字，这条通知不会 @ 人。

**推送的文字能改吗？** 能，但不在群里改——那是控制台推送页的事，
见[第 6 章](06-add-streamer-and-push.md)。

群里发 `@机器人 菜单` 会收到下面这样的回复（示例里本群没有禁用命令，也没有开问数）。

```
用法：@ 我，后面接命令名，例如「菜单」。

可用命令：

【提醒订阅】
@名单 [开播|动态] [主播 uid 或昵称] — 查看提醒订阅名单，可带「开播」或「动态」
动态@我 [主播 uid 或昵称] — 开关动态提醒：没订就订上，订了就取消
开播@我 [主播 uid 或昵称] — 开关开播提醒：没订就订上，订了就取消

【命令管理】
启用命令 <命令名> — 在本群启用某个命令
禁用命令 <命令名> — 在本群禁用某个命令
菜单 — 列出可用命令

【数据查询】
直播报告 [主播 uid 或昵称] — 看直播报告：直播中看到此刻，下播后看上一场
```
