# 第 8 章　群里怎么用命令

这一章是写给**群里的人**看的：怎么查数据、拉报告、订阅提醒。控制台的管理员
不用记这些，转发这一章就行。先说怎么发才算命令，再给整张命令表和几句常见问法。

## 怎么发才算命令

- **群里要先 @ 机器人**：`@机器人 命令名 参数`，比如 `@机器人 数据排行榜 礼物`。
  没 @ 的消息一概不理——群里聊天随口说到某个命令名，它不该接话
- **私聊直接发命令名**，不用 @
- 机器人**只在配置过推送的群里应答**；没配过的群里 @ 了它也不说话
- @ 了但不是命令（包括只 @ 了一下什么都没写），它会回一份**菜单**，
  顶行写着当前会话该怎么发命令；发 `菜单` 也是这一份
- 同一个群 **3 秒内只回一次**：执行命令、回菜单、回「已关闭」「没权限」
  共用这一份冷却，防的是刷屏

## 命令表

| 命令 | 别名 | 做什么 | 谁能用 |
|---|---|---|---|
| `菜单` | `帮助` `命令` | 列出可用命令 | 所有人 |
| `启用命令 <名称>` | | 恢复一条被本群关掉的命令 | 仅管理员 |
| `禁用命令 <名称>` | | 在本群关掉一条命令 | 仅管理员 |
| `开播@我 [主播]` | `取消开播@我` | 订阅开播时被 @；**开关式**，再发一次就是取消 | 所有人 |
| `动态@我 [主播]` | `取消动态@我` | 订阅发动态时被 @；同样是开关式 | 所有人 |
| `@名单 [开播｜动态] [主播]` | `开播@名单` `动态@名单` | 看订阅名单；不写「开播 / 动态」就两份都看 | 所有人 |
| `直播报告 [主播]` | | 直播中随时拉一份实时报告图，不必等下播 | 所有人 |
| `直播间数据 [总] [主播]` | `直播间总数据` | 直播间整体数据；带「总」查历场累计 | 所有人 |
| `数据排行榜 <榜单> [总] [主播]` | `总数据排行榜` | 查一张榜单，回一张长图，默认列前 50 名（图装不下时少列几名，图末写明还有几名没列出） | 所有人 |

几点说明：

- **参数怎么摆**：榜单名照写、放在最前；「总」写在哪里都行
  （`数据排行榜 总 弹幕` 与 `数据排行榜 弹幕 总` 一样）；主播放最后，昵称或 uid
  都认。这个群只配了一位主播时，主播可以省略；配了多位时必须带上是哪一位。
  三位以内的纯数字照收但不用——那是旧版翻页用的页码，现在一张长图全装下了
- **榜单有六张**：弹幕、礼物、醒目留言（`SC`）、盲盒、盲盒盈亏（`盈亏`）、
  大航海（`舰长`）。金额不可见的会话里，礼物、醒目留言、盲盒盈亏这三张查不了，
  它会明说「本会话不展示金额相关的榜单」，并列出还能查哪几张
- **「总」要先开才有**：没开累计数据时，它会说「本机没开累计数据，只能查本场」，
  而不是回一堆 0 让人以为数据丢了。开的地方在控制台设置页的「累计数据 Redis」，
  填好即生效，不用重启；Redis 只需本机可达，**不要暴露到公网**
- **管理员是谁**：群主、群管理员自动就是；机器人的主人未必是每个群的管理员，
  可以在设置页「超级管理员」里填一份跨群生效的名单
- **`@名单` 只写群昵称**（取不到时退回 QQ 昵称），不列 QQ 号
- 旧命令名（`取消开播@我`、`总数据排行榜` 这些）**仍然可用**，菜单里只列新名

## 常见问法

**@ 了怎么不理我？** 按顺序查：这个群配过推送吗（没配的群一概不应答）；
这条命令被本群关了吗（被关的会回「本群已关闭该命令」，不是沉默）；三秒内是不是
已经让它回过一次；最后才是——你发的是命令吗，聊天里提到命令名不算。

**「数据排行榜 云山 礼物」怎么反问我榜单名？** 榜单名要放在最前，
主播名放最后：`数据排行榜 礼物 云山`。

**想让开播消息 @ 我？** 自己发 `@机器人 开播@我` 就行，不用找管理员；
不想被 @ 了再发一次同一句。

**推送的文字能改吗？** 能，但不在群里改——那是控制台推送页的事，
见[第 6 章](06-add-streamer-and-push.md)。
